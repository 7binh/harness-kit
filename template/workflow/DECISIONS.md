# Decision Log

Append-only. One entry for each decision a future session could not recover from the code alone:
a choice between real alternatives, a rule that overrides a document, or something the user ruled on.
Newest at the bottom. Never edit an old entry; add a new one that supersedes it.

```markdown
## D-NNN — Title (YYYY-MM-DD)
**Decision**: what was chosen.
**Why**: the reason, including the alternative that lost.
**Affects**: files, features, or documents this changes how you read.
```
